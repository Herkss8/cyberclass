О проекте

CyberClass — интерактивный тренажёр цифровой безопасности. Он помогает проверить и закрепить навыки безопасной работы в сети: распознавание фишинга, управление паролями и двухфакторной аутентификацией, защита устройств и персональных данных, осторожность в публичных сетях.

Проект ориентирован на жителей и сотрудников организаций, которые хотят повысить цифровую грамотность. После каждого ответа показывается разбор и ссылка на тему из справочника. Результаты сохраняются локально в браузере.

Справочник

Понятия из учебной литературы по информационной безопасности и криптографии, изложенные кратко.

Конфиденциальность, целостность, доступность (CIA)

Базовая триада свойств защиты информации. Конфиденциальность — доступ только для авторизованных субъектов, целостность — неизменность данных без санкции, доступность — доступ к ресурсам в нужное время.

Хеширование паролей

Для паролей применяют медленные функции (bcrypt, scrypt, Argon2) с уникальной солью. Соль затрудняет радужные таблицы, медленность увеличивает стоимость перебора.

Режимы блочного шифрования

ECB шифрует блоки независимо — структура данных просвечивает. Режимы CBC, CTR с корректным IV/nonce этого недостатка лишены.

Симметричное и асимметричное шифрование

AES быстр, но требует безопасной передачи ключа. RSA и ECC используют пару ключей и применяются для обмена симметричным ключом в гибридных схемах.

Инфраструктура открытых ключей (PKI)

УЦ подписывает сертификаты, связывая открытый ключ с владельцем. Доверие — по цепочке до доверенного корня. Самоподписанный сертификат браузер помечает предупреждением.

Двухфакторная аутентификация

Знание, владение, биометрия. Два фактора из разных групп повышают защиту. SMS уязвимы к перехвату — приложения-генераторы и аппаратные ключи надёжнее.

Принцип наименьших привилегий и Zero Trust

Только необходимые права. Zero Trust проверяет каждый запрос и не доверяет субъекту лишь из-за местоположения в сети. В быту — отзыв ненужных разрешений у приложений.

Реагирование на инцидент

Подготовка → обнаружение → сдерживание → устранение → восстановление → анализ. При угоне аккаунта: смена пароля, завершение чужих сессий, сохранение логов.
